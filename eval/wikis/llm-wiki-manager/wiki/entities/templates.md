# Templates (`templates/`)

Scope tag: **`templates`** (first tag).

Init copies **`templates/wiki/`** and amends root **`templates/AGENTS.md`** into consumer projects. Wiki management logic ships in the published package (`dist/`), not as copied script files.

## Directory layout

| Path        | Role                                                                       |
| ----------- | -------------------------------------------------------------------------- |
| `wiki/`     | Wiki skeleton copied by init (see sub-table below)                         |
| `AGENTS.md` | Repo-root agent pointer template (amended into consumer `AGENTS.md`)       |
| `scripts/`  | Legacy `.mjs` mirror for this repo's dogfood sync — **not** copied by init |

### `templates/wiki/`

| File             | Role                                    |
| ---------------- | --------------------------------------- |
| `schema.md`      | Full wiki spec for consumer vaults      |
| `AGENTS.md`      | Vault agent entry (copied to `wiki/`)   |
| `README.md`      | Human onboarding                        |
| `index.md`       | Index scaffold (regenerated by `build`) |
| `log.md`         | Event log scaffold                      |
| `raw/raw.md`     | Raw sources hub                         |
| `.entity-scopes` | Required entity overview slugs for lint |

Upgrade refreshes meta paths listed in `WIKI_META_UPGRADE_PATHS` in `src/utils/fs.ts`; init-only paths (`index.md`, `log.md`) are created on first init but not overwritten on re-init. Root `AGENTS.md` refreshes use managed markers and ignore copied end-marker examples inside fenced code.
